# Line Help — отдельная HTML-вёрстка

Откройте `index.html` в браузере или загрузите всю папку на любой статический хостинг.

## Состав

- `index.html` — вся разметка главной страницы;
- `assets/css/style.css` — стили и адаптив;
- `assets/js/main.js` — мобильное меню;
- `assets/migrated/` — локальные фото, логотип и шрифты.

Иконки загружаются из Font Awesome CDN. Для полностью офлайн-версии замените CDN на локальный пакет Font Awesome.

Форма в HTML демонстрационная: она показывает подтверждение, но не отправляет заявку. Для рабочего приёма заявок требуется подключить обработчик формы или API.
